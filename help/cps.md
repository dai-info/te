# CPS – Curl Program Script

> Hilfe zum Dateityp `.cps` (auch `.cpu`, `.cpy`, `.cpx`).
> Diese Datei ist die **Vorlage** für Lexer-Hilfen in TE: einfach kopieren,
> umbenennen (z. B. `f2p.md`) und Inhalte ersetzen. Sie wird beim Aufruf von
> **Hilfe zum Dateityp** (`Shift+F1`) als formatiertes HTML in der Vorschau
> angezeigt. `Esc` schließt die Hilfe wieder.

---

## Überblick

Kurze Beschreibung der Sprache: wofür `.cps`-Dateien verwendet werden, wie eine
typische Datei aufgebaut ist und worauf der Lexer beim Highlighting achtet.

## Syntax-Grundlagen

- **Kommentare:** beginnen mit `#` am Zeilenanfang.
- **Schlüsselwörter:** in der Tabelle unten aufgeführt.
- **Zeichenfolgen / Werte:** hier Regeln ergänzen.

```cps
# Beispielzeile – wird in der Vorschau farblich hervorgehoben
KEYWORD argument1 argument2
```

## Schlüsselwörter

| Schlüsselwort | Bedeutung                       | Beispiel              |
|---------------|---------------------------------|-----------------------|
| `KEYWORD1`    | Was es bewirkt                  | `KEYWORD1 wert`       |
| `KEYWORD2`    | Was es bewirkt                  | `KEYWORD2 a, b`       |

## Beispiel

```cps
# Vollständiges Mini-Beispiel
KEYWORD1 wert
KEYWORD2 a, b
```
